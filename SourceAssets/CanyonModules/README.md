# Treasure Sketch 峡谷模块 Demo

本包是峡谷随机地图的第一批几何资产，不包含预制游戏关卡。`CanyonModules_Source.blend` 是 Blender 5.2.2 源文件；每个 `SM_*.glb` 是独立的 UE 导入资产。

## 连接约定

- Blender 使用米制，局部 `+X` 为前进，`+Y` 为左岸，`+Z` 为高度。
- 每段长 24 米；入口中心 `(0, 0, 0)`，出口中心 `(24, 0, rise_m)`。
- 每段由左岩壁、右岩壁和谷底三个 GLB 组成，三者使用相同变换。
- 两端谷底半宽 9.7 米，岩壁截面一致；中段宽度、侵蚀形状和岩层色彩各有变化。
- `Straight_A`、`Straight_B_Wide`、`Straight_C_Narrow` 为平地；`Rise_3m` 与 `Fall_3m` 的出口分别高 3 米和低 3 米。
- `CanyonModules_manifest.json` 包含所有文件名、连接点和高度信息。

## UE 接入建议

导入 GLB 后，每段实例把对应的三件网格挂到同一个 Actor。世界坐标按 UE 厘米制换算，拼接时将下一段的入口对齐上一段的出口。第一版可用复杂碰撞验证行走；在正式地图中应简化碰撞并检查性能。碎岩可放在墙脚和连接处，以掩饰重复边缘。

这批资产用于验证直线段、宽窄变化及高差。岔路与大角度弯道需要 UE 的过渡地形或后续专用模块；直接旋转相邻直线段会产生楔形缝隙。
