# TreasureSketch

## 房间设置与自动交图

- 探索者等待地图时显示服务端同步的绘图倒计时。绘图到时自动交付当前图纸，开始独立的寻宝倒计时；地图师也可提前按 Enter 交图。
- 图纸笔画以小批次可靠同步到服务端，自动交付使用服务端收到的当前图纸；清空图纸同步清空缓存，每局缓存独立。
- 房主在大厅可切换“宝藏判定范围：显示／隐藏”。此项只控制宝藏周围的圆柱和圆形判定范围可视化，保留宝藏位置的红色标记，不改变实际挖掘范围。
- 房主可切换“出生点：同一区域／分散登岛”。同一区域使用附近安全位置避免角色重叠；分散模式让探索者与地图师从不同区域登岛。默认同一区域。
- 以上设置开局锁定，重玩和返回大厅时保留，单人完整流程测试也支持判定范围开关。
- 结算后房主选择“全队返回大厅”可重新调整设置；客户端显示由房主操作的说明。单人结算可返回测试菜单。

这是“观察岛屿并手绘藏宝图，再把图交给另一名玩家寻宝”的双人联网验证版。

## 本分支主要更新

### 岛屿生成

- 扩大了整体可探索岛屿面积，给观察、画图和寻找过程留出更多空间。
- 岛屿外围轮廓不再只是近似圆形，增加长脊、月牙、海湾、尖角和弯钩等可辨认轮廓。
- 增加一个大岛加一个小岛、两个中型岛和三个近距离小岛等分岛变种。
- 分岛之间保持很短的浅水距离；当前宝藏仍只生成在陆地上。
- 同一种分岛类型也会根据种子改变轮廓、比例和局部起伏，不是重复使用完全相同的地图。
- 沙滩主题增加平地、单峰、双峰、山脊、边缘峭壁、盆地和丘陵等地形组合，减少每局中央固定一座山的重复感。
- 新增集中式主题选择表，可统一调整主题权重、默认解锁状态、植被密度和地形起伏，方便以后加入其他岛屿主题。

### 场景资产

- 海盗沙滩主题增加棕榈树、岩石、灌木、漂流木以及多种可用于画图定位的海盗地标。
- 新增丛林遗迹原型资产：双层神庙、瞭望塔、神龛大厅、地穴入口和探险者小屋。
- 新增板根树、分叉丛林树、灌木、蕨类和倒木，并为遗迹主题提供独立的密集植被生成方式。
- 修正树木碰撞体明显大于模型的问题。
- 增加遗迹石材、苔藓、树皮、树叶和蕨类的颜色映射；仍需在实际游戏画面中继续检查最终效果。
- 新增大型森林主题及四类无外露树根的树木，并加入灌木、蕨类、芦苇等密集遮挡植被。
- 森林加入小湖、苔藓巨石、裂石、叠石、石板、空心树桩和蘑菇圈等定位物。
- 森林地形加入高丘、长山脊、低洼谷地和连续缓坡；树木保持直立，低矮地面资产会适配坡面。

### 游戏流程与界面

- 新增带实时岛屿远景的主页面：创建房间、加入房间、单人探险、设置和退出游戏。
- 创建房间后进入独立房间页面，可邀请 Steam 好友、查看人数并由房主开始游戏。
- 房间内新增离开房间并返回主菜单的流程。
- 绘图和寻宝阶段时间由 60 秒调整为 120 秒。
- 两名玩家使用不同出生位置，并避免出生在水中。
- 红色 X 增加完整的三维挖掘判定范围显示，方便测试水平距离和高度差。
- 增加单人地图测试菜单，可快速选择大型迷雾森林、海盗沙滩岛或随机主题；此功能目前仅用于开发检查。

## 双人联网原型

- 玩家 1 是 Listen Server，第一局担任侦察者。
- 玩家 2 是连接到主机的客户端，第一局担任寻宝者。
- 每局结束后可选择保持角色或交换角色，后续角色不再绑定主机和客户端。
- 服务器生成岛屿种子、藏宝坐标、阶段与倒计时。
- 寻宝者在交图前停留在等待画面，不会获得藏宝坐标。
- 侦察者按 Enter 后一次性提交完整手绘图，寻宝者随后登岛。
- 寻宝者的挖掘请求由服务器判定。
- 编辑器默认使用 2 Players、Play As Listen Server、独立游戏窗口进行测试。

## 本轮验证什么

1. 每局使用新种子生成不同岛屿轮廓与起伏。
2. 侦察者能看见红色 X，并在完全空白的纸上自由画岛形、地形和藏宝点。
3. 按 Enter 交图后切换到寻宝者；红色 X 隐藏，手绘笔画保留。
4. 寻宝者按 M 查看图纸，在岛上按 E 挖掘。距离藏宝点 4.25 米内成功。
5. 交图后侦察者可自由飞行观战、切换寻宝者第一视角，并单独开关宝藏标记；交换角色后两人都能使用观战。

## Steam 大厅操作

- `H`：创建 Steam 房间
- `I`：房主打开 Steam Overlay 好友邀请界面
- `J`：刷新房间列表
- `K`：加入列表中的第一个房间
- `P`：两名玩家到齐后由房主开始游戏

## 游戏操作

- `WASD`：移动
- 鼠标：视角
- `Space`：跳跃
- `M`：打开/收起白纸地图
- 侦察者在纸上按住鼠标左键：画线
- `C`：侦察者清空画纸
- `Enter`：侦察者把地图交给寻宝者
- `E`：寻宝者挖掘
- 侦察者交图后进入观战；`WASD` 自由飞行，`Space` 上升，`Ctrl` 下降，`Shift` 加速，鼠标转向
- 观战时按 `Tab` 在自由飞行和寻宝者第一视角之间切换；按 `T` 仅在自己画面上显示或隐藏藏宝标记
- 寻宝者使用简易人形占位模型；交图后侦察者的原角色隐藏并停止碰撞，鬼魂镜头不会显示给寻宝者
- `R`：生成新岛屿并开始新一局
- 侦察者与寻宝者默认各有 120 秒；房主可在大厅分别调整绘图与寻宝时间。交图后按寻宝时间重新计时。
- 找到宝藏或寻宝阶段超时后，全队进入结算，可选择保持角色或轮换地图师重玩；房主还可让全队返回大厅。绘图阶段超时会自动交图，不再直接结束一局。

## 开始测试

联机大厅右侧提供地图面积倍数（可输入 0.5–5，如 1.5、2、3.25；1 倍时沙滩约 125 米边长、森林约 94 米边长，加减按钮每次 0.25 倍）、绘图时间和寻宝时间设置。时间以 30 秒为步长，范围 30–600 秒；仅房主可改，所有成员可见，开局后锁定，重玩保留。默认标准地图、两个阶段各 120 秒。

房主还可在大厅的“地图池”中分别启用海盗沙滩和迷雾森林，至少保留一种。默认两种都启用；开局后从已启用的主题中随机选图。地图池对全员可见，开局锁定，重玩及返回大厅后保留。

单人菜单中的“探索者玩法测试”和“完整流程测试”使用相同的大小、时间设置，并可指定种子。原来的三个地图场景测试仍使用标准大小与一小时测试时间。结算后，单人可返回测试菜单，联机房主可让全队返回大厅调整设置，无需重建房间。

打开 `TreasureSketch.uproject`，等待首次编译，然后在编辑器中点击 Play。

公网开发测试目前使用 Steam 测试 AppID 480。正式发布前必须替换为项目自己的 Steam AppID。

推荐测试方式：双方先运行游戏，房主按 `H` 创建房间并进入等待页，再按 `I` 从 Steam Overlay 邀请好友。好友接受后会自动加入。公共房间搜索保留为备用与诊断用途。

地图倍率同时调整资源目标数量：面积倍率为 s 时，边长按 √s 缩放，树木、灌木、石头及地标目标数量按 s 缩放，单个模型与人物大小不变；最终数量仍受地形、坡度与间距约束。森林已替代遗迹进入随机主题池，遗迹素材保留。

森林基础资源数量按新的约 94 米基准范围的面积比例折算，保留原森林密度，避免把原大森林的全部资源塞入较小的标准地图。倍率调整的是生成范围面积，实际陆地面积仍随岛屿形状变化。

联机大厅和两个单人玩法测试支持移动速度 0.5–5 倍，每次加减 0.25 倍，默认 1 倍（5.2 米/秒）。房主设置会同步给所有玩家；地图师与探索者使用相同倍率，重玩保留。倍率同步调整加速和刹车，不改变跳跃高度或观战飞行速度。

## 多地图师、单个探索者模式

房主在大厅点击“多名地图师，一名探索者”选择模式。支持 2–4 人：一人为探索者，其余各自探索同一座岛、绘制独立图纸；切换模式时原来的唯一地图师变为唯一探索者，大厅玩家列表同步显示角色。

- 每位地图师按 Enter 交付自己的图纸，交图后等待其余地图师，不能继续修改图纸或喷漆。
- 全部地图师交图后立即进入寻宝；绘图时间到则自动收齐未完成图纸，包括空白图纸。提前交付的图纸保留，重复交图不能覆盖。
- 探索者等待期间直接观看地图师实时画纸，同时显示绘图倒计时与已交图人数；多地图师可用左右方向键或“上一张 / 下一张”按钮切换画纸。已提交图纸保留，清空只影响对应作者。寻宝开始后按 M 查看图纸并继续翻页；页脚显示作者与页码。
- 所有地图师在寻宝阶段可自由飞行观战，或按 Tab 跟随唯一探索者第一视角；观战时按 M 查看只读图纸，多地图师可翻页比较各自的最终地图。看图时镜头暂停，关图后继续观战。
- 结算可保持角色重玩，或选择“轮换探索者，再玩一次”；返回大厅保留模式与设置。
- 结算还可选择“留在岛上复盘”：全队回到刚才的岛屿自由走动，宝藏位置对所有人显示，最终图纸可按 M 查看并翻页；复盘时按 Esc 返回结算，再选择重玩或回大厅。复盘期间无法继续挖掘或修改图纸。
- 大厅新成员加入时自动补齐角色。有人离开会返回大厅；唯一探索者离开后自动指定新的探索者。
- 出生点模式、判定范围显示、面积、时间、速度和实验喷漆设置沿用现有房间设置。
- 单地图师、多探索者模式同样支持等待时实时观看画纸；探索者只能观看，不能修改。
